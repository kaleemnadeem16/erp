# Quotation list presentation preview

This is a disabled presentation exercise for the owner-authorised Batch B UI. It has no route, navigation entry, network implementation or production fixture data. `QuotationListScreen` is hard-denied by default; its separately exported presentation is used only by a browser fixture. No list client is generated yet. The existing generated `QuotationDraftResource` is an unknown dictionary, so the preview validates only the fields in the proposed #56 safe summary, strips all other properties, and refuses malformed summaries. This is provisional, not approval or a declaration that the final endpoint implements the proposal.

The mock presentation uses the shared table/cards, with detail and review links, status, references, dates and line count. It receives server-owned page totals, ordering and callbacks and never derives access, totals or filters from a partial page. Party and currency IDs are temporary labelled references; meaningful authorised lookup labels are needed before activation. The endpoint is deferred until QA1–QA3 and its own approved contract. Reconcile pagination, filtering, sorting, safe fields, record eligibility and the generated client against that contract before any network wiring or exposure; never create a client-side record visibility rule. No actual financial data or customer line contents belong in this summary.

After `npm run build` in `frontend/`, run `docker/frontend/run-e2e.sh quotation-list-preview.unit.spec.ts --project=unit` from the repository root. The fixture intercepts every request and uses only synthetic rows. It checks projection and financial-extra stripping, the off gate, a real keyboard link activation, and 390px overflow and serious/critical accessibility findings. These tests do not prove server visibility, real pagination or activation readiness.
